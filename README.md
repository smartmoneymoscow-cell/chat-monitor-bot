# Chat Monitor Bot — Telegram-бот с inline-меню

Интерактивный бот для мониторинга Telegram-чатов по ключевым словам.

## Что делает

- Пользователь заходит в бота → видит inline-меню с кнопками
- Настраивает Telethon-аккаунт (от имени которого мониторит чаты)
- Добавляет чаты и ключевые слова
- Указывает, куда слать уведомления (себе / в группу / в канал)
- Бот мониторит и пересылает совпадения с информацией: чат, автор, ссылка, текст

## Установка

```bash
pip install telethon python-telegram-bot
```

## Настройка config.py

```python
# Бот-токен от @BotFather
BOT_TOKEN = "123456:ABC-DEF..."

# Telethon API — с https://my.telegram.org
TELETHON_API_ID = 12345678
TELETHON_API_HASH = "abcdef1234567890..."
```

## Запуск

```bash
python3 bot.py
```

## Меню бота

```
📱 Добавить аккаунт        — авторизация Telethon (телефон → код → 2FA)
💬 Добавить чаты            — ID или @username чатов для мониторинга
🔑 Добавить ключевые слова — слова-триггеры для поиска
🔔 Куда слать уведомления  — ID чата / "me" (себе в ЛС)
📋 Мои настройки           — текущий конфиг
▶️ Запустить мониторинг     — включить отслеживание
⏹ Остановить мониторинг    — выключить
```

## Порядок настройки

1. **Добавить аккаунт** → ввести номер телефона → ввести код из Telegram
2. **Добавить чаты** → выбрать аккаунт → ввести ID/@username чатов
3. **Добавить ключевые слова** → выбрать аккаунт → ввести слова
4. **Куда слать** → `me` (себе) или числовой ID группы
5. **Запустить мониторинг**

## Как узнать ID чата

- Переслать сообщение из чата боту [@userinfobot](https://t.me/userinfobot)
- Или: запустить бота → он покажет ID при авторизации

## Как работает

```
┌─────────────────────────────────────────────┐
│  Telegram Bot (python-telegram-bot)          │
│  Inline-меню, настройки, уведомления         │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  Telethon (userbot) — фоновый поток          │
│  Мониторит чаты, ищет ключевые слова         │
│  При совпадении → отправляет через Bot API   │
└─────────────────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  JSON-хранилище (data/user_*.json)           │
│  Настройки каждого пользователя              │
└─────────────────────────────────────────────┘
```

## Важно

- Telethon — это **юзербот** (работает от реального аккаунта Telegram)
- Нужен отдельный Telegram API (с https://my.telegram.org), это **не** Bot API
- Сессия сохраняется в файл — повторный вход не нужен
- Можно мониторить только чаты, в которых состоит авторизованный аккаунт
